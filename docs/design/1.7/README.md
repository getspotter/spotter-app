# Entwürfe Spotter 1.7

Mockups im iPhone-Format 390 × 844, je hell und dunkel.
Bei Widerspruch zwischen Bild und Auftrag gilt der Auftrag. Beispieldaten sind keine Vorgaben.

| Datei | Inhalt |
|---|---|
| einheit-detail | Detail einer Einheit: Tafel „Übungen verbessert“ oben, Übungsliste mit Schildern |
| rezepte-sammlung | Rezepte: Sammlung / Meine Rezepte, Filter, Protein pro Portion, Zugang Einkaufsliste |
| rezept | Rezeptansicht: Makros pro Portion, Portionen anpassen, Zutaten, Zubereitung |
| einkaufsliste | Gemeinsame Einkaufsliste nach Abteilungen, wer was abgehakt hat |
| einkaufsliste-auswahl | Zutaten vor dem Übernehmen abwählen; Vorrat ist vorab abgewählt; Hinweis bei Zutaten, die schon auf der Liste stehen |
| einkaufsliste-eintrag | Tipp auf einen Eintrag: Menge ändern oder löschen |

Zutaten mit `"vorrat": true` sind beim Übernehmen vorab abgewählt.

Die Rezeptdaten liegen in `daten/rezepte.json` (12 Rezepte, Stand 2026-11).
Nährwerte sind Richtwerte aus typischen Packungsangaben, gerechnet mit Rohgewichten.
